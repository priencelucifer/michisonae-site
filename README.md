# MichiSonae site

Public pages for the MichiSonae Android app, served by GitHub Pages:

- [Privacy policy](https://priencelucifer.github.io/michisonae-site/privacy.html), generated from `docs/release/PRIVACY_NOTICE_DRAFT.md` in the app's repository. Change the notice there first, then regenerate and push:

  ```sh
  python notice_to_html.py path/to/PRIVACY_NOTICE_DRAFT.md privacy.html
  ```

- [Delete your data](https://priencelucifer.github.io/michisonae-site/delete-data.html), written by hand from the notice's retention section; keep the two in step.
